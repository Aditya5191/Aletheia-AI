## Installation

### Step 1 — Run the installer

```bash
npx create-aletheia-skill@latest
```

You will see:

```
╔════════════════════════════════════════╗
║   Aletheia Fairness Auditor            ║
```

## 🟠 Claude Code

<img src="https://upload.wikimedia.org/wikipedia/commons/thumb/8/8a/Claude_AI_logo.svg/1024px-Claude_AI_logo.svg.png" width="30"/> **Claude Code / Claude Desktop**

After running the installer with Claude Code selected, it will generate a `.plugin` file and tell you its path.

**Manual steps:**

1. Open **Claude** (desktop or web)
2. Go to **Settings**
3. Click **Connectors** in the left sidebar
4. Click **Create +** → **Upload plugin**
5. Upload the `.plugin` file generated by the installer

```
Claude → Settings → Connectors → Create + → Upload plugin
```

**Verification:** Aletheia will appear under **Personal plugins** in the Connectors panel with an enabled toggle.

```
Personal plugins
  ✓ Aletheia  [Enabled ●]
```

**Using it:**

Open a new Claude conversation and say:

```
The Aletheia sandbox container is already built.
Audit this dataset: [attach your CSV file]
```

or for model auditing:

```
The Aletheia sandbox container is already built.
Audit this classification model: [attach .pkl and sample.csv]
```

Claude will orchestrate all four agents and stream the results live in the conversation.

## What the Skill Does When Active

Regardless of which agent you use, once the Aletheia skill is active, it:

1. **Detects intent** — activates when you mention bias, fairness, disparate impact, model discrimination, or similar terms
2. **Starts the Docker sandbox** — spins up an isolated container on your machine
3. **Orchestrates the 4-agent pipeline** — all agents run sequentially, streaming their activity
4. **Delivers outputs** — PDF report, fixed dataset or correction map, charts, all saved to your working directory

## Privacy in Plugin Mode

The plugin connects your coding agent to the Aletheia MCP server for **algorithm knowledge only**. Your dataset and model files are processed locally inside Docker and are never transmitted anywhere.

→ **[Full Privacy Documentation](PRIVACY.md)**

```
Plugin Mode Data Flow:
  Your File → Local Docker → Local Agent Execution
                  ↓
            MCP Server (algorithm IDs only, no data)
                  ↓
            LLM API (reasoning, no data in prompts)
                  ↓
            Output Files → Your Working Directory
```

## Troubleshooting

**Container not starting:**
```bash
docker ps  # Check Docker is running
docker build -t sandbox-python:latest ./mcps/sandbox/  # Rebuild if needed
```

**Skill not activating:**
Restart your coding agent after installation. The skill must be loaded at startup.

**MCP server not connecting:**
```bash
# Check MCP servers are running
curl http://localhost:8000/
curl http://localhost:8001/sse
curl http://localhost:8002/sse
```

**Output files not found:**
Check your working directory. Outputs are saved to `./outputs/` relative to where you ran the agent.
